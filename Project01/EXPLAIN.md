# Project01 — Follow the Gap 주행 코드 설명

ESP32 하나가 LiDAR 한 바퀴 스캔마다 전방 180° 안에서 차가 지나갈 수 있는 방향을 찾아 그쪽으로 주행한다. 지도와 위치 추정 없이 현재 스캔만으로 판단하는 반응형 장애물 회피이며, Follow the Gap Method(Sezer & Gokasan, 2012)의 "장애물을 차 폭만큼 부풀린 뒤 열린 방향으로 간다"는 생각을 따른다.

## 라이브러리 사용

- 외부 라이브러리: 없음. ESP32 Arduino 코어(`esp32:esp32` 4.0.0)의 기본 함수만 쓴다.

## 실행 흐름

```text
LiDAR 47B 패킷 (Serial2 RX16, 230400 baud, CRC-8 검증)
   │  pollLidar → processLidarPacket: 12점 각도 보간, distances[360]에 1° 단위 저장
   ▼  360°→0° 전환 = 한 바퀴 완성 (약 6 Hz)
decide
   ├ 가변저항 5% 미만 → 정지
   ├ markBlocked: 점마다 막는 방향 표시
   ├ chooseTarget: 0°에 가장 가까운 열린 방향 선택
   ├ aheadDist: 정면 통로 거리로 감속
   ▼
applyVelocity → 4채널 LEDC PWM
loop: 한 바퀴 스캔이 500 ms 넘게 없으면 정지
```

## 주행 규칙

각도 a는 차 정면이 0°이고 왼쪽이 +이다. LiDAR 원시 각도(0=뒤, 90=왼쪽, 180=앞)에서 `a = 180 - raw`로 바꾼다.

1. **막힌 방향**: 거리 d가 `MIN_D`(180 mm)보다 멀고 `D_FREE`(700 mm)보다 가까운 점은 a ± asin(R/d) 범위를 막는다. 그 방향으로 직진하면 점과의 옆 간격이 R보다 좁아지는 범위다. d ≤ R이면 ±90°를 막는다. 거리 0(측정 없음)은 장애물로 보지 않는다.
2. **목표 방향**: 왼쪽과 오른쪽에서 각각 0°에 가장 가까운 열린 각을 찾는다. 지난번에 피한 쪽(`side`) 후보가 반대쪽보다 `H_DEG`(15°) 넘게 멀지 않으면 그쪽을 고른다. 정면 장애물 앞에서 스캔 잡음으로 목표가 좌우로 바뀌는 떨림을 막는다.
3. **목표가 없을 때**: `side` 쪽으로 제자리 회전한다. 회전 중에는 `side`를 바꾸지 않는다.
4. **명령**: `w = K_W · 목표`, `v목표 = V_CRUISE · 가변저항 비율 · max(0, 1 − |목표|/45°) · slow`. `slow`는 정면 폭 2R 통로 안 가장 가까운 점의 앞쪽 거리를 `D_STOP`(300 mm)–`D_FREE` 사이에서 0–1로 바꾼 값이다. v는 스캔마다 `DV`까지만 올리고, 줄일 때는 바로 반영한다.
5. **정지**: 가변저항이 5% 미만이거나 한 바퀴 스캔이 500 ms 넘게 없으면 모터를 끈다.

규칙 1과 4는 같은 R을 쓴다. 통로 안에 점이 있으면 0°가 반드시 막히므로, v가 0일 때 w도 0이 되어 멈춰 버리는 경우가 없다.

## 함수별 핵심 로직

| 함수 | 동작 |
| --- | --- |
| `pollLidar` · `processLidarPacket` · `calcCrc8` | 헤더 `0x54 0x2C`로 47B 패킷을 모으고 CRC-8(다항식 `0x4D`)을 확인한 뒤, 시작·끝 각도로 12점 각도를 보간해 `distances[]`에 넣는다. 한 바퀴가 끝나면 `decide`를 부르고 배열을 비운다. |
| `markBlocked` | 규칙 1. 전방 −90..90° 배열 `blocked[]`에 점마다 막는 범위를 표시한다. |
| `nearestOpen` · `chooseTarget` | 규칙 2. 0°부터 1°씩 넓혀 각 쪽의 첫 열린 각을 찾고, `side`로 한쪽을 고른다. |
| `aheadDist` | 정면 반원의 점을 x(앞), y(왼쪽)로 바꿔 \|y\| < R인 점 중 가장 작은 x를 돌려준다. 없으면 `D_FREE`. |
| `decide` | 규칙 3–5를 적용해 v, w를 정한다. 가변저항이 5% 미만이어도 판단은 계속하고 출력만 0으로 둔다. |
| `printStatus` | 500 ms마다 Serial Monitor(115200 baud)에 `target`(목표 각, 없으면 `none`), `side`, `pot`, `v`, `w`, `ahead`(정면 통로 거리 mm)를 한 줄로 출력한다. |
| `applyVelocity` · `setMotorChannel` | 왼쪽 = (v − w)·`MAX_PWM`, 오른쪽 = (v + w)·`MAX_PWM`으로 섞는다. 0이 아닌 명령은 모터 데드존을 넘도록 `MIN_PWM`–`MAX_PWM`으로 매핑한다. |

## 상수

| 상수 | 값 | 정하는 방법 |
| --- | --- | --- |
| `R_MM` | 250 | 차폭/2 + 150 mm. 차폭을 재서 고친다. |
| `MIN_D` | 180 | 정지 상태 360° 거리에서 차체가 잡히는 거리보다 크게 둔다. |
| `V_CRUISE` | 0.4 | 순항 출력에서 0.33 s(스캔 수집 + 명령 유지) 동안 가는 거리와 정지 거리의 합이 `D_STOP` − 차 길이/2보다 작아야 한다. |
| `D_FREE` · `D_STOP` | 700 · 300 | 통로 폭과 차 길이에 맞춰 조정한다. |
| `K_W` · `W_TURN` · `DV` | 0.01 · 0.5 · 0.1 | 주행을 보며 조정한다. |
| `MOTOR_SIGN` | {1, 1, 1, 1} | 반대로 도는 바퀴만 −1로 바꾼다. |

## 업로드와 실행

1. GPIO 0·12·15는 부팅 모드를 정하는 핀이므로 모터 전원을 끈 상태에서 `Project01/follow-the-gap/follow-the-gap.ino`를 `ESP32 Dev Module`로 업로드한다.
2. 가변저항을 0으로 돌려 두고 모터 전원을 켠다. 부팅 비프음이 울리면 Serial Monitor에서 `pot=0.00` 근처 값을 확인한다. 이 상태에서 차 앞에 손을 대면 모터는 멈춘 채 `ahead`가 줄고, 왼쪽 앞에 대면 `target`이 −로 바뀐다.
3. 가변저항을 올리면 그 비율만큼의 순항 출력으로 출발한다.
